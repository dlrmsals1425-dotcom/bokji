## 3. 제안 (a~e 평가)

| 안 | 평가 | 시험판 |
|---|---|---|
| (a) '지금 받고 있는 지원' + 없음 + 모름 | 채택. 다만 생계(32%) ⊂ 의료(40%) ⊂ 주거(48%) ⊂ 교육·차상위(50%)로 기준이 겹치므로 여러 개 고르기보다 '가장 높은 단계 하나'가 쉽다. 기초연금은 따로 예/아니오/모름 | 구현 |
| (b) 월 소득(원) × 가구원 수 → 기준 중위소득 구간 | 채택. 2026 기준 중위소득 1~6인(보건복지부, 아래 출처)으로 자동 계산, 소득인정액(재산 환산)과 다를 수 있다는 안내. 건강보험료로 짐작하기는 공식 환산표를 확인하지 못해 보류 | 구현 |
| (c) '내 상황을 적어 주세요' 문장 칸 | 채택. 기존 해석기로 칸을 채우고 '이렇게 이해했어요' 표시 | 구현 |
| (d) 답과 맞지 않는 혜택은 본문에서 빼고, 모름은 맨 위 질문 하나 블록 | 채택. 질문은 최대 3개, 정해지는 혜택의 관련도 순(기초연금·돌봄처럼 중요한 혜택을 정하는 질문 먼저). 답하면 바로 다시 계산, '모름'이면 다음 질문 | 구현 |
| (e) 카드 문구를 이용자 말로 | 채택. 예) '가구 소득이 월 419만원 이하 (2인 가구 기준) — 부모님이 해당돼요', '부부 소득인정액이 월 395만 2천원 이하이면 받을 수 있어요', '기초생활수급자·차상위계층인 분 대상이라 맞지 않아요' | 구현 |

### 질문 12개 (모두 '모름' 있음)

1. 사는 곳 (시·도 / 시·군·구) — 유일한 필수
2. 나이 (만 나이 구간 · 문장의 출생연도로 자동)
3. 함께 사는 가족 수
4. 주민센터에서 받는 지원: 없음 / 생계급여(매달 생활비) / 의료급여(병원비를 의료급여증으로) / 주거급여만 / 차상위계층 / 잘 모르겠어요
5. 기초연금을 받나요 (60세 이상일 때)
6. 가구의 한 달 소득 (만원) → '2인 가구 기준중위소득의 약 71% — 기초생활보장·차상위 소득 기준(50%)보다 높아요'
7. 장애인 등록: 아니요 / 심한 장애 / 심하지 않은 장애
8. 식사·거동·외출에 도움이 필요한가요
9. 장기요양등급을 받았나요 (60세 이상일 때)
10. 집: 자가 / 전세 / 월세 / 공공임대
11. 일: 일해요 / 일자리를 찾고 있어요 / 아니요
12. 보훈 대상인가요

+ 선택: 상황 문장 칸. 추가 질문(필요할 때만): 진단받은 병(치매·암·희귀질환), 조손·한부모, 다문화, 혼자 사는지(가구원 수 모름일 때).
본인 모드(60세 미만)에서는 5·9 대신 자녀 나이·한부모를 묻는 것이 맞다 (시험판은 부모님 모드 기준).

## 4. 결과 화면 (시험판)

네 묶음으로 나눈다: **받으실 수 있어요**(검수된 규칙으로 조건이 모두 맞음) · **신청할 때 확인**(어긋나는 조건은 없고 원문 세부 조건만 남음) ·
**답하면 정해져요**(접힘, 맨 위 질문으로 갈림) · **맞지 않아 뺐어요**(접힘, 이유 표시).

정한 규칙:
- 원문(이름·지원 대상 앞부분)에 '수급자·차상위'만 있으면 수급 관문, '저소득'(숫자 없음)은 기준 중위소득 60% 이하로 봄(운영자 결정 필요), '중위소득 N% 이하'는 그 숫자로. '…우선'은 관문 아님. 대상이 여러 유형으로 나뉘고 일부만 소득 조건이면 관문 없음.
- 소득이 기준 중위소득 60%를 넘으면 기초생활수급·차상위는 아닌 것으로 추정 (화면에 알림).
- 기초연금을 받으면 '소득 하위 70%' 조건은 맞음. 안 받는다고 해서 아니라고 보지는 않음.
- 원천 태그(soft) 조건은 답과 달라도 빼지 않음 — 감사에서 장애인연금·장기요양 등이 잘못 빠지는 것을 확인.
- 자동 정리 규칙(원문 대조 전)은 조건이 다 맞아도 '받으실 수 있어요'가 아니라 '신청할 때 확인'.
- 긴급지원, 이름 괄호에 대상이 따로 있는 사업(예: 무료 소송대리 서비스(가족관계미등록자))도 '신청할 때 확인'.
